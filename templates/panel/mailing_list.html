Set up the list (once)

Six settings on Mailman, before anyone is added
  1. Members only, kept private. {% if pages.roster_privacy %}Privacy options → Subscription rules{% else %}Privacy options → Subscription rules{% endif %}: “What steps are required for subscription?” → Confirm and approve (or anyone could join by emailing the list), and “Who can view subscription list?” → List admin only.
  2. Make it announce-only. {% if pages.senders %}Privacy options → Sender filters{% else %}Privacy options → Sender filters{% endif %}: “By default, should new list member postings be moderated?” → Yes, and “Action to take when a moderated member posts” → Reject. Leave “Action to take for postings from non-members…” on Hold. For anyone already on the list: {% if pages.members %}Membership List{% else %}Membership List{% endif %} → “Set everyone's moderation bit” → On → Set.
  3. Keep the archive private. {% if pages.archive %}Archiving options{% else %}Archiving options{% endif %}: “Is archive file source for public or private archival?” → private{% if public_archive %}, then check that {{ public_archive }} no longer opens without a login{% endif %}. The What's On lists members-only events.
  4. No password emails. {% if pages.general %}General options{% else %}General options{% endif %}: “Send monthly password reminders?” → No.
  5. Say how to leave. {% if pages.footer %}Non-digest options{% else %}Non-digest options{% endif %}: add to “Footer added to mail sent to regular list members”: To leave this list, email {{ leave_address|default:"the list's -request address" }} from the address this came to, with the subject unsubscribe, and reply to the confirmation it sends. Its own pages need an SRCF or University login, which some old-list people don't have.
  6. Keep the society's own addresses off it: {{ sender_address|default:"the address the mailer sends from" }} and {{ contact_email }}, which the mailer sends from and asks replies to go to.

Sending the What's On to the list

Four steps, and the one trap on Mailman's approval page
  1. On the Mailer, choose “One address” (it starts on the list) and send.
  2. Mailman holds it, because the site isn't a subscriber, and emails mss-admins.
  3. On the {% if pages.held %}waiting posts page{% else %}waiting posts page{% endif %}, posts are grouped by sender, and Accept there releases every post held from that address. If yours (check its subject and time) is the only one, choose Accept. If anything else is held from it (an older What's On, or something you didn't send: anyone can fake a From address), open yours by its number, choose Approve, and Discard the rest. Leave the boxes to add the sender to a filter, or to ban it, unticked.
  4. Send each What's On either to the list or to the website's audiences, not both, or people on both get it twice.
